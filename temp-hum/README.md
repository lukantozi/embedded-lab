# temp-hum

Temperature and humidity monitor using atmega328p and
dht11 module.

## Build, flash, and run:

```sh
make flrun
```

### Wiring notes to me in the future:
*(my module is distinct from the one in the datasheet)*

Looking at the blue sensor face with the three connector
pins pointing down, leftmost module pin is connected to
arduino pin 6, middle one to 5V and the rightmost to gnd.
